# Important-EXE-File

🇸🇦

**تنويه مهم بخصوص ملفات EXE**

اغلب الملفات سويتها باستخدام **PyInstaller** عشان احول مشاريع Python لملفات EXE، وفيه بعض المشاريع سويتها باستخدام **JavaScript وJava**.

عشان كذا ممكن تطلع لكم تحذيرات لما تفحصوا الملفات في **VirusTotal**، وبعض التحذيرات تكون غلط (False Positives)، خصوصا لو الملفات جديدة وما هي معروفة عند برامج الحماية.

**ملاحظة:** مو كل تحذير يعني ان الملف فيه فيروس، لكن برضه يفضل تتاكدوا من سلامة الملفات قبل تشغيلها حق من حقوقكم.

---

🇺🇸 **English | Important Notice**

Most executable files were packaged using **PyInstaller** to convert Python projects into standalone EXE applications, while some other projects were developed using **JavaScript and Java**.

Because of this, some files may trigger warnings on **VirusTotal**. These detections can sometimes be false positives, especially for newly developed applications that are not widely recognized by antivirus software.

**Note:** A security warning does not necessarily mean a file is malicious. However, verifying file safety before running any executable is always recommended.
